# Product

## Register

brand

## Users

Context Vault is for developers, founders, AI power users, and small teams building software with AI coding tools. They switch between Codex, Cursor, Claude, Windsurf, Claude Code, and other MCP-compatible clients while trying to preserve project intent, architecture decisions, constraints, issues, and next steps.

## Product Purpose

Context Vault is a persistent cross-AI project memory layer for AI-assisted development. GitHub stores code; Context Vault stores AI-readable project understanding so every connected AI tool can continue from the same source of truth.

Success means a visitor quickly understands the product category, trusts the review-first memory model, sees MCP as the core integration path, and knows how GitHub changes become reviewable context suggestions.

## Brand Personality

Calm, exacting, infrastructure-native. The brand should feel like a serious developer tool that rewards careful work, not an AI novelty product.

## Anti-references

Avoid generic AI startup pages, robot illustrations, cyberpunk neon, excessive gradients, childish icons, hackathon placeholder visuals, vague AI buzzwords, oversized card grids, and claims the product does not support.

## Design Principles

- Make the product concrete in the first viewport with realistic UI, command snippets, and integration states.
- Explain the memory model through contrasts developers already understand: code versus intent, chat history versus structured context, auto-capture versus review-first approval.
- Keep the visual system restrained, dark, and production-grade so it feels trustworthy to engineers.
- Show control and safety as product mechanics, not as generic trust copy.
- Prefer dense, scannable sections over inflated marketing spacing.

## Accessibility & Inclusion

Use clear semantic structure, keyboard-friendly navigation, strong contrast on dark surfaces, responsive layouts without horizontal overflow, and reduced-motion fallbacks for decorative movement.
